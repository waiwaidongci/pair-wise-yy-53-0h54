# 影视内容发行权窗口与独占冲突审阅平台

源提示词编号：10。维护作品、权利类型、地区、语言、窗口、独占和次级授权，联动时间轴与地区矩阵，检测重叠、交叉、倒挂和独占冲突，支持批量调窗、版本差异、评论锚点、审批和追溯导出。

## 授权链（母窗口 → 次级授权 → 冲突结论）

- 母窗口的「允许次级授权」是链开关：只有开着转授权才能登记次级窗口。
- 次级登记受三类硬约束：日期不早于/晚于母窗口、地区包含于母窗口（东南亚区域含新加坡/马来西亚）、母窗口非独占时次级不得独占。
- 母窗口范围（日期/地区/独占/转授权）一变，链上次级窗口立即重新核验：越界即「已失效-超出母窗口」；关闭转授权则整条链失效，重新开启且边界仍包含时恢复生效。
- 冲突结论分四档：有效 / 部分次级失效 / 整链失效 / 待核验。
- 两人同时提交「母窗口调整」和「次级登记」时，服务端按 revision 乐观锁串行处理：先到生效并推进版本，后到不覆盖先到结果，保留为「草稿-冲突」挂在链上并展示越界原因，处理完母窗口后可按当前版本重新提交。`/chains` 的「并发提交演练」可模拟两种到达顺序。
- 存量数据迁移：没有母窗口引用的旧次级登记，按作品 / 权利类型 / 转授权开关 / 日期 / 地区 / 独占边界自动挂到唯一母窗口；找不到或命中多个的保留为「待核验」，由法务人工指定母窗口（仍受硬校验）。本地持久化版本升级到 v2 时也会跑同一迁移。
